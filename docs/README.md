# SproutKeeper Application
A Python and PyQt6 GUI application for taking care of a plant nursery.

## Plant Nursery
A plant nursery is a place where plants are grown for transplanting, for use as stock for budding and grafting, or for sale.
These are often used for gardening, forestry, or conservation biology.

## Project Status
SproutKeeper is currently under active development. I will update when core functionality is available and when additional features are planned for future releases.
